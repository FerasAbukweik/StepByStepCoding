## بيانات جرى تجهيزها

- مقرر Programming Foundations وشعبة Section A، مع حسابات مدرّسة وطلاب وتسجيلات فعلية.
- محاضرات مجدولة ومنتهية، وبيانات كافية لإظهار تحميل الصفحة التالية عند الوصول إلى نهاية القائمة.
- اختبار عملي أُنجز وصُحح وأُغلق، واختبار مسودة واختبار قادم منشور.
- مساحة عمل شخصية للطالب مع ملف Java محفوظ؛ ظهر تشغيل Python وC++ وJava في الجولة.
- مقررات وشُعب إضافية أُنشئت أو عُدّلت من الواجهة أثناء التسجيل.
