Specification Note

Post-Authentication Routing & Redirect Matrix (Annotation Sheet)

Standard Direct Sign-In
Role Default Landing
  • • admin → /admin/users
  • • instructor → /instructor/courses
  • • student → /student/live (Screen 1)
Protected URL Redirection
Target Page Permission Check

If intercepted by auth check (e.g. ?return_to=/cs201/exam/midterm), validate authenticated user's role against target page ACL before redirecting.

Unauthorized Target Access
Route to Access Denied

If the signed-in role cannot access the requested route (e.g. a student trying to open /admin/users), route directly to the Access Denied Screen inside the standard shell.
