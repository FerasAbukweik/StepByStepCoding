Ergonomics Spec

Mobile Behavioral Contract

  • 1. Persistent Live Banner: Slides in below the header whenever a student is outside an active lecture. Provides a guaranteed ≥ 44px tap target to jump into code.
  • 2. Drawer Integration: "My Lectures" moves directly into the mobile drawer, retaining the identical 4-state lifecycle (Scheduled, Waiting, Live, Ended) with zero feature loss.
  • 3. Tabular Unstacking: Wide multi-column tables cleanly break into 2-line stacked card rows to eliminate horizontal scrolling while keeping timestamps aligned.
  • 4. Accessibility Guarantee: Polite screen-reader live region (`aria-live="polite"`) quietly announces when an instructor turns a lecture live without visual interruptions.
Touch targets calibrated to iOS Human Interface & Android Material guidelines.
